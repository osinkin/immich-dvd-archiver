# Immich DVD Archiver

[![Python](https://img.shields.io/badge/python-3.10%2B-blue)](https://www.python.org/)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)
[![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Linux-lightgrey)](#требования)

**English version:** [README.md](README.md)

Уменьшает фотографии из библиотеки [Immich](https://immich.app/) до рамки 1920×1080 и
раскладывает результат по папкам дисков — чтобы архив помещался на DVD. Исходная
библиотека открывается **только на чтение** и никогда не изменяется.

Программа рассчитана на архивирование библиотеки Immich на оптические носители: она
сохраняет дату съёмки в структуре папок, упаковывает файлы в диски заданного размера и
продолжает работу после прерывания, не обрабатывая готовые файлы повторно.

## Возможности

- Вписывает изображения в рамку 1920×1080 с сохранением пропорций; не увеличивает их.
- Раскладывает результат по дате съёмки из EXIF: `<год>/<год-месяц-день>/<дата_время_имя>.jpg`.
- Разбивает результат на папки `disc_01`, `disc_02`, … с настраиваемым лимитом
  (по умолчанию 4.3 ГиБ — практический объём DVD-R).
- Конвертирует PNG, WebP, TIFF, BMP и HEIC/HEIF в JPEG; прозрачность накладывает на белый
  фон; уже подходящие JPEG копирует байт-в-байт без перекодирования.
- Сохраняет EXIF (кроме тега Orientation); есть минимальный режим без MakerNotes и GPS.
- Пропускает RAW и видео, записывая их в `skipped.csv`.
- Продолжает работу по `manifest.csv`; атомарная запись не оставляет недописанных файлов.
- Оценивает объём и число дисков без записи, а при нажатии «Старт» предлагает использовать
  уже собранный список файлов.
- Работает на Windows и Linux, есть GUI на Tkinter и режим без интерфейса (CLI).
- Интерфейс на русском и английском языках.

## Требования

- Python 3.10 или новее (проверено на 3.11 и 3.12).
- Pillow и pillow-heif (ставятся из `requirements.txt` или как зависимости пакета).
- Tkinter нужен только для GUI. В официальном установщике Python для Windows он есть;
  в Linux устанавливается отдельно (`sudo apt install python3-tk`).

## Установка

```bash
git clone https://github.com/OWNER/immich-dvd-archiver.git
cd immich-dvd-archiver
python -m pip install -r requirements.txt
```

Или установка как пакета с командой `immich-dvd`:

```bash
python -m pip install .
immich-dvd --help
```

### Windows

```bat
run.bat
```

или

```bat
python -m immich_dvd
```

### Linux

```bash
./run.sh              # GUI
# или
python3 -m immich_dvd
```

## Как пользоваться

### GUI

1. **Библиотека Immich** — папка `library` (например, `\\server\immich\library`) или папка
   конкретного пользователя внутри неё. Можно указать и корень данных Immich: служебные
   каталоги `thumbs`, `encoded-video`, `upload`, `profile` и `.immich` пропускаются
   автоматически.
2. **Папка результата** — локальный диск или другая шара. Не может находиться внутри
   библиотеки.
3. **Оценить** — быстрый проход без записи: сколько файлов, ожидаемый объём, сколько
   дисков и сколько свободно в папке назначения.
4. **Старт** — обработка. Прогресс-бар показывает проценты, объём, скорость и оставшееся
   время. Кнопка **Отмена** останавливает работу после текущего файла; повторный запуск
   продолжит с места остановки. Если перед этим была сделана оценка, программа предложит
   использовать уже собранный список файлов — повторное сканирование библиотеки не
   потребуется.

### CLI

```bash
# только оценка объёма, ничего не пишется
python3 -m immich_dvd --no-gui \
  --source /mnt/immich/library --dest /mnt/archive --estimate

# обработка
python3 -m immich_dvd --no-gui \
  --source /mnt/immich/library --dest /mnt/archive --disc-size 4.3
```

Все параметры: `python3 -m immich_dvd --help`.

| Параметр | Описание |
| --- | --- |
| `--source PATH` | Папка библиотеки Immich (только чтение) |
| `--dest PATH` | Папка результата |
| `--estimate` | Сканировать и вывести оценку, ничего не записывая |
| `--no-gui` / `--gui` | Принудительно без интерфейса или с интерфейсом |
| `--lang {ru,en}` | Язык интерфейса |
| `--max-width PX`, `--max-height PX` | Рамка (по умолчанию 1920×1080) |
| `--quality N` | Качество JPEG, 50–95 (по умолчанию 85) |
| `--disc-size GIB` | Лимит диска в ГиБ (по умолчанию 4.3) |
| `--split` / `--no-split` | Включить или отключить папки дисков |
| `--exif` / `--no-exif` | Сохранять или удалять EXIF |
| `--minimal-exif` | Оставить только основные теги EXIF (без MakerNotes/GPS) |
| `--skip-existing` / `--no-skip-existing` | Пропускать файлы, уже записанные в `manifest.csv` |
| `--workers N` | Число процессов (0 = авто) |
| `--quiet` | Печатать только предупреждения и итог |

Если графическое окружение недоступно, программа подскажет режим `--no-gui`.
Ctrl+C останавливает работу после текущего файла; следующий запуск продолжит с места
остановки.

## Что получается на выходе

```
dest/
  disc_01/
    2019/
      2019-07-04/
        2019-07-04_121530_IMG_0421.jpg
    MANIFEST.csv
    README.txt
  disc_02/
    ...
  manifest.csv          # общий список: источник → результат, размеры, диск
  skipped.csv           # RAW, видео и прочее, что не вошло
  errors.csv            # файлы, которые не удалось прочитать или обработать
  _REPORT.txt           # итоговая сводка
```

- Дата берётся из EXIF (`DateTimeOriginal` → `DateTimeDigitized` → `DateTime`), иначе из
  даты изменения файла.
- Имя файла — дата/время съёмки плюс исходное имя (если Immich сохранил `.xmp` sidecar)
  или первые 8 символов идентификатора Immich.
- Изображения вписываются в рамку 1920×1080 с сохранением пропорций, **без увеличения**.
  Портретное фото станет 1080×1920, кадр 4:3 — 1440×1080.
- Всё сохраняется в JPEG (качество по умолчанию 85, настраивается). PNG/WebP/TIFF/BMP/HEIC
  конвертируются, прозрачность накладывается на белый фон, анимированные GIF/WebP берут
  первый кадр.
- Если JPEG уже меньше рамки, он копируется байт-в-байт без перекодирования.
- EXIF сохраняется (тег Orientation убирается). Опция «Минимальный EXIF» оставляет только
  основные поля камеры и съёмки, удаляя MakerNotes и GPS.
- Разбивка на диски идёт по фактическому размеру файлов; граница может попасть внутрь
  одного дня. Лимит по умолчанию 4.3 ГиБ — практический объём DVD-R.

## Возобновление и безопасность

- `manifest.csv` — источник правды. При повторном запуске уже записанные файлы
  пропускаются, счётчики дисков восстанавливаются.
- Запись идёт через `*.tmp` и атомарное переименование; недописанных файлов не остаётся.
- Источник открывается только на чтение. Программа откажется работать, если папка
  результата вложена в источник или наоборот.
- Immich во время работы можно не останавливать: файлы читаются, ничего не блокируется.
  Если Immich одновременно удалит фото, оно попадёт в `errors.csv`.

## Ограничения

- RAW (`.dng`, `.cr2`, `.arw`, …) и видео не обрабатываются — перечисляются в
  `skipped.csv`.
- Исходные имена файлов в библиотеке Immich заменены на UUID; человекочитаемое имя
  восстанавливается только при наличии `.xmp` sidecar.
- Оценка объёма приблизительная (±20 %): точный размер JPEG зависит от содержимого кадра.
- Часовой пояс EXIF не учитывается — дата остаётся локальной, как её записала камера.

## Производительность

Обработка идёт в нескольких процессах (по умолчанию `min(CPU, 8)`). Узкое место при работе
по сети — чтение мелких файлов с шары; 4–8 потоков обычно ускоряют работу в разы. Поле
«Потоков» позволяет подобрать значение под конкретную шару (0 — авто).

## Язык интерфейса

- В GUI — переключатель **«Язык»** в блоке **«Параметры»** (Русский / English). Выбор
  сохраняется в `config.json`.
- В CLI — `--lang ru` или `--lang en`.
- Если язык не задан, он определяется по локали системы (`LANG`/`LC_ALL`), иначе
  используется английский.

Настройки сохраняются в `config.json` в пользовательской папке конфигурации
(`%APPDATA%\immich-dvd` в Windows, `~/.config/immich-dvd` в Linux). Файл `config.json`
рядом с пакетом по-прежнему используется, если он уже существует; путь можно переопределить
переменной `IMMICH_DVD_CONFIG`.

## Разработка

```bash
python -m pip install -e ".[dev]"
python -m pytest -q
python -m ruff check .
```

Тесты покрывают сканирование, ресайз, работу с EXIF, упаковку дисков, продолжение после
прерывания, переиспользование списка из оценки и каталоги переводов. В тестах
многопроцессорность заменяется синхронным пулом, чтобы всё работало на Windows и Linux без
побочных эффектов spawn.

## Структура проекта

```
immich_dvd/
  gui.py       # окно, прогресс, журнал
  cli.py       # точка входа argparse и режим без интерфейса
  job.py       # оркестрация, оценка, пул процессов
  scanner.py   # обход библиотеки, EXIF-даты, фильтры
  resizer.py   # ресайз и конвертация (worker)
  writer.py    # диски, манифест, отчёты, resume
  config.py    # сохранение настроек в config.json
  i18n.py      # строки на русском и английском
  models.py    # общие структуры данных
tests/         # тесты pytest
```
