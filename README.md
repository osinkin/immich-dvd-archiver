# Immich DVD Archiver

Уменьшает фотографии из библиотеки Immich до рамки 1920×1080 и раскладывает результат
по папкам дисков — чтобы архив помещался на DVD. Исходная библиотека открывается
**только на чтение** и никогда не изменяется.

## Установка

```bat
cd D:\projects\immich-backup
python -m pip install -r requirements.txt
```

Нужен Python 3.10+ (проверено на 3.11). Tkinter входит в стандартную поставку Python для Windows.

## Запуск

```bat
run.bat
```

или

```bat
python -m immich_dvd
```

## Как пользоваться

1. **Библиотека Immich** — папка `library` (например, `\\server\immich\library`) или папка
   конкретного пользователя внутри неё. Можно указать и корень данных Immich: служебные
   каталоги `thumbs`, `encoded-video`, `upload`, `profile`, `.immich` пропускаются автоматически.
2. **Папка результата** — локальный диск или другая шара. Не может находиться внутри библиотеки.
3. **Оценить** — быстрый проход без записи: сколько файлов, ожидаемый объём, сколько дисков,
   сколько свободно в папке назначения.
4. **Старт** — обработка. Прогресс-бар показывает проценты, объём, скорость и оставшееся время.
   Кнопка **Отмена** останавливает работу после текущего файла; повторный запуск продолжит
   с места остановки.

## Что получается на выходе

```
dest/
  disc_01/
    2019/
      2019-07-04/
        2019-07-04_121530_IMG_0421.jpg
    MANIFEST.csv
    README.txt
  disc_02/
    ...
  manifest.csv          # общий список: источник → результат, размеры
  skipped.csv           # RAW, видео и прочее, что не вошло
  errors.csv            # файлы, которые не удалось прочитать
  _REPORT.txt           # итоговая сводка
```

- Дата берётся из EXIF (`DateTimeOriginal` → `DateTimeDigitized` → `DateTime`), иначе из даты файла.
- Имя файла — дата/время съёмки плюс исходное имя (если Immich сохранил `.xmp` sidecar)
  или первые 8 символов идентификатора Immich.
- Изображения вписываются в рамку 1920×1080 с сохранением пропорций, **без увеличения**.
  Портретное фото станет 1080×1920, кадр 4:3 — 1440×1080.
- Всё сохраняется в JPEG (качество по умолчанию 85, настраивается). PNG/WebP/TIFF/BMP/HEIC
  конвертируются, прозрачность накладывается на белый фон, анимированные GIF/WebP берут первый кадр.
- Если JPEG уже меньше рамки, он копируется байт-в-байт без перекодирования.
- EXIF сохраняется (тег Orientation убирается). Опция «Минимальный EXIF» оставляет только
  основные поля камеры и съёмки, удаляя MakerNotes и GPS.
- Разбивка на диски идёт по фактическому размеру файлов; граница может попасть внутрь одного дня.
  Лимит по умолчанию 4.3 ГиБ — практический объём DVD-R.

## Возобновление и безопасность

- `manifest.csv` — источник правды. При повторном запуске уже записанные файлы пропускаются,
  счётчики дисков восстанавливаются.
- Запись идёт через `*.tmp` и атомарное переименование; недописанных файлов не остаётся.
- Источник открывается только на чтение. Программа откажется работать, если папка результата
  вложена в источник или наоборот.
- Immich во время работы можно не останавливать: файлы читаются, ничего не блокируется.
  Если Immich одновременно удалит фото, оно попадёт в `errors.csv`.

## Ограничения

- RAW (`.dng`, `.cr2`, `.arw`, …) и видео не обрабатываются — перечисляются в `skipped.csv`.
- Исходные имена файлов в библиотеке Immich заменены на UUID; человекочитаемое имя
  восстанавливается только при наличии `.xmp` sidecar.
- Оценка объёма приблизительная (±20 %): точный размер JPEG зависит от содержимого кадра.
- Часовой пояс EXIF не учитывается — дата остаётся локальной, как её записала камера.

## Производительность

Обработка идёт в нескольких процессах (по умолчанию min(CPU, 8)). Узкое место при работе
по сети — чтение мелких файлов с шары; 4–8 потоков обычно ускоряют работу в разы.
Поле «Потоков» позволяет подобрать значение под конкретную шару (0 — авто).

## Структура проекта

```
immich_dvd/
  gui.py       # окно, прогресс, журнал
  job.py       # оркестрация, оценка, пул процессов
  scanner.py   # обход библиотеки, EXIF-даты, фильтры
  resizer.py   # ресайз и конвертация (worker)
  writer.py    # диски, манифест, отчёты, resume
  config.py    # сохранение настроек в config.json
  models.py    # общие структуры данных
```
